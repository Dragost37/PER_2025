Maquette UX – Storytelling Notebook
Page 1 / 6 • Scénario 1

Ce notebook s’inscrit dans le cadre de la compétition Titanic – Machine Learning from Disaster et vise à construire un modèle de machine learning capable de prédire la survie des passagers du Titanic à partir des données fournies. Après une phase d’importation des bibliothèques nécessaires et de chargement des fichiers train.csv et test.csv, le notebook présente les données et décrit leurs principales caractéristiques à l’aide d’affichages des premières lignes, des dimensions et des informations sur les colonnes. Une analyse exploratoire est ensuite réalisée, conformément aux cellules Markdown explicatives, afin de visualiser la distribution de la variable cible Survived et son lien avec différentes variables explicatives telles que Sex, Pclass, Age et Embarked. Le notebook détaille ensuite les étapes de préparation des données : suppression de certaines colonnes jugées non pertinentes (Name, Ticket, Cabin), traitement des valeurs manquantes pour Age, Embarked et Fare, encodage des variables catégorielles par one-hot encoding et standardisation des variables numériques. Ces transformations sont regroupées dans un pipeline à l’aide d’un ColumnTransformer. Le modèle choisi, tel qu’indiqué dans le Markdown, est une régression logistique, entraînée sur le jeu d’entraînement et évaluée par validation croisée, les scores de précision étant affichés dans les sorties correspondantes. Enfin, le pipeline est entraîné sur l’ensemble des données d’entraînement afin de produire les prédictions finales sur le jeu de test, lesquelles sont enregistrées dans un fichier submission.csv respectant le format requis pour la soumission.
