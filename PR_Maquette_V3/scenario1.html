Scénario 1 – Résumé narratif avant le code

Vous ouvrez un notebook de machine learning composé d’environ quarante cellules de code et de visualisations. Avant toute ligne de code, un texte d’une page maximum vous est présenté.

Ce texte explique :

  • le problème initial que le notebook cherche à résoudre,
  • la nature des données utilisées,
  • les grandes étapes suivies dans l’analyse,
  • un point de difficulté rencontré en cours de route,
  • et le résultat final obtenu.

Le texte est rédigé comme un récit continu, sans afficher de code, mais en mentionnant explicitement les décisions prises et les résultats observés. À la fin du texte, le notebook reste accessible cellule par cellule.
