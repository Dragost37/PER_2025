Page 1 / 6 • Scénario 1

Le notebook Titanic – Machine Learning from Disaster a pour objectif de prédire la survie des passagers du Titanic à partir de données socio-démographiques et de voyage, en formulant le problème comme une tâche de classification binaire supervisée. Il débute par l’importation des bibliothèques usuelles (pandas, numpy, matplotlib, seaborn, scikit-learn) et le chargement des jeux de données d’entraînement et de test, dont la structure est examinée à l’aide des premières cellules (head(), shape, info()) afin d’identifier les types de variables et les valeurs manquantes. Une analyse exploratoire détaillée est ensuite conduite à travers plusieurs cellules de visualisation pour étudier la relation entre la variable cible Survived et des caractéristiques clés telles que le sexe, la classe (Pclass), l’âge et le port d’embarquement, révélant des résultats marquants : les femmes présentent un taux de survie très nettement supérieur à celui des hommes, les passagers de première classe survivent davantage que ceux des classes inférieures, et les individus les plus jeunes bénéficient globalement d’un avantage. À partir de ces constats, une phase de prétraitement est mise en œuvre : les variables jugées peu informatives ou trop incomplètes (Name, Ticket, Cabin) sont supprimées, les valeurs manquantes de Age, Embarked et Fare sont imputées par des statistiques simples (médiane ou valeur la plus fréquente), tandis que les variables catégorielles (Sex, Embarked) sont transformées par one-hot encoding et les variables numériques standardisées. L’ensemble de ces traitements est encapsulé dans un ColumnTransformer intégré à un pipeline scikit-learn, garantissant un prétraitement cohérent et reproductible sur les données d’entraînement et de test. Le modèle retenu est une régression logistique, entraînée sur les données préparées et évaluée par validation croisée, avec une précision moyenne comprise entre 78 % et 80 %, indiquant que le modèle capture efficacement les tendances majeures mises en évidence lors de l’analyse exploratoire, en particulier l’impact déterminant du sexe et de la classe sociale. Ce score constitue une performance de référence solide pour ce jeu de données, bien qu’il reste perfectible. Le pipeline est ensuite ré-entraîné sur l’intégralité du jeu d’entraînement afin de maximiser l’information disponible, puis utilisé pour générer les prédictions finales sur le jeu de test ; ces prédictions sont exportées dans un fichier submission.csv conforme au format attendu pour la soumission. Dans l’ensemble, les résultats montrent qu’un modèle linéaire simple, correctement prétraité, permet déjà d’obtenir des performances satisfaisantes, tout en soulignant les limites de l’approche, notamment l’absence de feature engineering avancé ou de modèles plus complexes, faisant de ce notebook une base méthodologique claire, robuste et pédagogique.
