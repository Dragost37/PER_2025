Page 1 / 6 • Scénario 1

Le notebook Titanic – Machine Learning from Disaster a pour objectif de prédire la variable Survived à partir des données du jeu d’entraînement fourni, dans le cadre d’un problème de classification supervisée. Il commence par l’importation des bibliothèques pandas, numpy, matplotlib, seaborn et des modules de scikit-learn, puis par le chargement des fichiers train.csv et test.csv, dont les premières lignes, les dimensions et les types de variables sont affichés à l’aide des méthodes head(), shape et info(). Plusieurs cellules sont ensuite consacrées à une analyse exploratoire des données, incluant des visualisations montrant la répartition de la variable Survived en fonction de variables telles que Sex, Pclass, Age et Embarked. Le notebook procède ensuite à un prétraitement des données : les colonnes Name, Ticket et Cabin sont supprimées, les valeurs manquantes de Age sont remplacées par la médiane, celles de Embarked par la valeur la plus fréquente, et la valeur manquante de Fare dans le jeu de test est également imputée. Les variables catégorielles Sex et Embarked sont encodées par one-hot encoding, tandis que les variables numériques sont standardisées, l’ensemble de ces transformations étant regroupé dans un ColumnTransformer intégré à un pipeline scikit-learn. Le modèle utilisé est une régression logistique, qui est entraînée sur les données d’entraînement prétraitées ; une évaluation est réalisée à l’aide d’une validation croisée, et les scores de précision obtenus sont affichés dans les sorties des cellules correspondantes. Enfin, le pipeline est entraîné sur l’intégralité du jeu d’entraînement et utilisé pour générer les prédictions du jeu de test, lesquelles sont stockées dans une colonne Survived et exportées dans un fichier submission.csv conforme au format attendu pour la soumission.
