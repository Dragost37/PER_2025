Patterns vs Performance

Visualisations globales liant structure des notebooks et scores de modèle.

• Heatmap : patterns (lignes) vs notebooks (colonnes) / performance
• Diagramme corrélation : nombre de patterns X → métrique Y
• Sélection d’un pattern pour voir les notebooks concernés
Possible ajout : timeline globale des workflows (inspirée “storytelling”), permettant d’identifier des familles de pipelines.

Artefacts & export

Vue agrégée des artefacts (datasets, modèles, métriques) produits par le corpus.

• Liste / tableau des artefacts agrégés
• Statistiques : combien de modèles, combien de jeux de données, etc.
• Filtrer par type de modèle, type de métrique, dataset.
Bloc “Export” :
• Export JSON / CSV des résultats d’analyse
• Export des patterns détectés par notebook
• Export des scores de qualité pour études ultérieures
